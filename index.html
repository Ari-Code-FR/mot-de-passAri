Gestionnaire de Mot de PassAri

Ce site est un gestionnaire de mot de passe qui ne stocke pas vos mots de passe.

Comment l'utiliser ?

Pour définir un mot de passe, il faut :

  1. Utiliser un mot de passe principal. Il est recommander d'utiliser un long mot de passe qui est facilement remémorable, par exemple en utilisant une phrase.
  2. Remplir le champ site/identifiant. Il s'agit de l'endroit où vous utilisez ce mot de passe (généralement, le site web). Cela permet d'avoir un mot de passe différent par site. Cette information doit être simple, car vous en aurez besoin pour récupérer votre mot de passe.
  3. Vous pouvez changer la version, si le mot de passe a été compromis, ou si vous souhaitiez avoir un second mot de passe.

Pour récuperer un mot de passe, il suffit d'entrer le même mot de passe principal, le même site/identifiant et la même version.

ATTENTION : Si vous perdez votre mot de passe principal ou l'identifiant d'un site, il est impossible de retrouver le mot de passe de ce site

Qu'est ce qu'est un gestionnaire de mot de passe ?

Le but d'un gestionnaire de mot de passe est de stocker et protéger tous vos mot de passe.

Pourquoi utiliser un gestionnaire de mot de passe ?

Il est généralement conseillé d'avoir un mot de passe pour chaque site, comme ça, si un site utilisant votre mot de passe s'est fait hacké, les autres site ne sont pas compromis car vous utilisez un mot de pase différent.

Pourquoi utiliser ce gestionnaire de mot de passe ?

Au lieu de stocker les mots de passe sur un appareil ou sur un serveur, celui-ci génére vos mots de passe a l'aide d'une fonction de hachage (argon2id), qui est irréversible, c'est à dire qu'il est impossible de retrouver le mot de passe principal à l'aide d'un mot de passe généré avec cette fonction.

Ce gestionnaire est utilisable sur n'importe quelle appareil, car chaque mot de passe est généré grâce au mot de passe principal.

Toutes les données sont traitées sur votre appareil et rien n'est enregistré, ni envoyé à un tier.
